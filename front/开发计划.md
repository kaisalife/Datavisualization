## 修改计划

### 步骤 1：修正 types.rs（P0 #1 #2 #3 + P1 #6）

**修改 TaskStatus 枚举：**
```rust
// 修改前
#[serde(rename_all = "lowercase")]
pub enum TaskStatus {
    Pending, Running, Succeeded, Failed,
}

// 修改后（匹配后端实际返回值）
#[serde(rename_all = "lowercase")]
pub enum TaskStatus {
    Pending, Running, Success, Failed,
}
```

**修改 TaskResult（匹配后端 GenerateChartWithPromptResponse）：**
```rust
// 修改前
pub struct TaskResult {
    pub charts: Option<Vec<ChartInfo>>,
    pub report_path: Option<String>,
}

// 修改后（后端字段名首字母大写）
pub struct TaskResult {
    #[serde(rename = "Charts")]
    pub charts: Vec<String>,           // 图表类型列表 ["Bar", "Line"]
    #[serde(rename = "HtmlFilePaths")]
    pub html_file_paths: Vec<String>,   // HTML 文件名 ["chart_1.html"]
    #[serde(rename = "AgentLogs", default)]
    pub agent_logs: Vec<String>,        // Agent 日志
}
```

**删除 ChartInfo（不再需要，后端不返回此结构）：**
```rust
// 删除
pub struct ChartInfo { ... }
```

**GenerateChartRequest 添加 config 字段：**
```rust
pub struct GenerateChartRequest {
    // ... 现有字段 ...
    pub config: Option<String>,  // 新增：图表配置 JSON
}
```

### 步骤 2：修正 client.rs（P0 #3 + P1 #5）

**修正 poll_task_until_done：**
```rust
// 修改前
TaskStatus::Succeeded => return Ok(task),
// 修改后
TaskStatus::Success => return Ok(task),
```

**增强错误处理（返回结构化错误）：**
```rust
// 新增错误类型
#[derive(Debug)]
pub enum ApiError {
    Unauthorized,         // 401
    NotFound(String),     // 404
    BadRequest(String),   // 400
    ServerError(String),  // 500
    NetworkError(String), // 网络错误
}
```

### 步骤 3：修正 main.rs on_generate（P1 #4 + P2 #8 #9）

**完整链路实现：**
```
on_generate()
  ├── 1. 读取提示词 + 校验文件
  ├── 2. set_status("正在提交任务...")
  ├── 3. std::thread::spawn
  │     ├── tokio::runtime::new()
  │     ├── client.generate_chart(&request)
  │     ├── set_status("任务已提交: {task_id}")
  │     ├── client.poll_task_until_done(&task_id)
  │     │     └── 每次轮询更新状态 "生成中... ({i}s)"
  │     ├── 成功: 提取 HtmlFilePaths
  │     │     └── 对每个文件: open_url(chart_url(file))
  │     └── 失败: set_status("生成失败: {error}")
  └── 4. 主线程立即返回，不阻塞 UI
```

**线程间通信（更新 UI 状态文本）：**
- 使用 `PostMessageW` 从工作线程发送自定义消息到主窗口
- 主窗口 `window_proc` 接收消息并更新状态文本
