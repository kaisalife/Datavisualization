## 详细描述

### P0 - 致命问题（3 个）

#### #1 无取消任务功能
- **位置：** `main.rs` on_generate
- **问题：** 用户提交任务后无法取消，工作线程一旦启动无法中断，轮询循环最多 5 分钟
- **影响：** 用户输错提示词/选错文件时只能关程序重来
- **后端现状：** 没有 cancel task 的 API

#### #3 WebSocket 路径丢失 Agent 日志
- **位置：** `main.rs` wait_for_completion_ws L1083-1092
- **问题：** 收到 success 通知时，构造 TaskResponse 只取了 `notif.result`，忽略了 `notif.agent_logs`
- **影响：** 主路径（WebSocket）下对话日志面板不显示后端执行日志
- **修复方案：** 把 `notif.agent_logs` 合并到 `TaskResponse.result.agent_logs`

#### #5 文件选择器多选可能丢文件
- **位置：** `file_picker.rs` L87
- **问题：** `String::from_utf16_lossy` 截断到第一个 `\0`，多选格式 `目录\0文件1\0文件2\0\0` 中第一个 `\0` 是目录分隔符
- **影响：** 多选时只拿到目录路径，文件名丢失
- **修复方案：** 直接遍历 `file_buffer` 而非 `raw`

### P1 - 重要问题（7 个）

#### #2 双状态管理冲突
- **位置：** `main.rs` APP_DATA vs `state/app_state.rs` AppState
- **问题：** 两套状态管理并存，AppState 完全未使用，pages/ 全是死代码
- **影响：** 维护成本，容易混淆

#### #4 对话 CRUD 只有列表
- **位置：** `main.rs` on_load_history / on_resubmit_prompt
- **问题：** 只有 list_conversations 有 UI 入口，get/delete/update_prompt 无 UI
- **影响：** 用户看得到历史但点不开、删不掉、改提示词不更新后端

#### #6 拖拽 vs 选择行为不一致
- **位置：** `main.rs` WM_DROPFILES vs on_pick_file
- **问题：** 拖拽追加文件，选择文件清空后替换
- **影响：** 用户拖了文件再点选择，拖拽文件丢失

#### #7 WebView2 未实现
- **位置：** `webview.rs` embed_webview2
- **问题：** 返回 Err，图表只能用 ShellExecuteW 外部浏览器打开
- **影响：** 用户体验差，图表不在应用窗口内

#### #8 高级参数无法配置
- **位置：** `main.rs` on_generate L658-669
- **问题：** model_url/model_type/model_api_key/mcp_prompt/skill_prompt/config 全硬编码 None
- **影响：** 用户无法切换模型、配置 MCP/技能提示词

#### #11 无 HTTP 重试机制
- **位置：** `client.rs` 所有方法
- **问题：** 所有 API 单次发送，网络抖动直接失败
- **影响：** 网络不稳定时任务提交失败

#### #13 轮询未复用 poll_task_until_done
- **位置：** `main.rs` L708-740 内联轮询 vs `client.rs` poll_task_until_done
- **问题：** 代码重复，行为略有不同（日志频率不同）
- **影响：** 维护成本

### P2 - 中等问题（6 个）

#### #12 无 WebSocket 重连机制
- **位置：** `main.rs` wait_for_completion_ws
- **问题：** 断开即回退轮询，不尝试重连
- **影响：** 短暂网络中断导致回退轮询

#### #14 WebSocket 成功路径 task_id 为空
- **位置：** `main.rs` L1088
- **问题：** TaskResponse.task_id = String::new()
- **影响：** 数据丢失（当前不影响功能）

#### #15 跨线程 UI 更新用 SendMessageW
- **位置：** `main.rs` update_status / append_log_ptr
- **问题：** SendMessageW 跨线程阻塞，应考虑 PostMessageW
- **影响：** 工作线程可能阻塞

#### #17 大文件上传全量读入内存
- **位置：** `client.rs` generate_chart L107-108
- **问题：** std::fs::read 同步读取整个文件
- **影响：** 大文件内存问题

#### #20 文件选择器过滤器缺类型
- **位置：** `file_picker.rs` L46-56
- **问题：** parquet/npz/zip 在 SUPPORTED_EXTENSIONS 但不在过滤器分组
