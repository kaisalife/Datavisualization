# 前端构建指南

## 环境要求

### 1. Rust 工具链

```powershell
# 安装 Rust（https://rustup.rs）
rustup-init.exe

# 确认 MSVC toolchain（默认已安装）
rustup default stable-x86_64-pc-windows-msvc

# 验证版本（需要 1.85+，因为使用 edition 2024）
rustc --version
```

### 2. VS Build Tools 2022

提供 `link.exe` 链接器，必须安装以下组件：
- **MSVC v143 - VS 2022 C++ x64/x86 生成工具**
- **Windows 11 SDK**（或 Windows 10 SDK 10.0.22621+）

下载地址：https://visualstudio.microsoft.com/visual-cpp-build-tools/

### 3. 不需要的东西

| 不需要 | 原因 |
|--------|------|
| Windows App SDK | 当前是纯 Win32 API，不是 WinUI3 |
| WinUI3 运行时 | 同上 |
| MSIX 打包工具 | 可选，仅在发布时需要 |
| .NET SDK | Rust 项目不需要 |

## 构建

### Debug 构建（开发用）

```powershell
cd front
cargo build
```

产物位置：`front/target/x86_64-pc-windows-msvc/debug/datavisual-frontend.exe`
- 体积：~8.5 MB（debug 模式）
- 编译时间：首次约 2 分钟，增量约 5 秒

### Release 构建（发布用）

```powershell
cd front
cargo build --release
```

产物位置：`front/target/x86_64-pc-windows-msvc/release/datavisual-frontend.exe`
- 体积：~3 MB（release 模式，已配置 `opt-level="z"` + `lto=true` + `strip=true`）
- 编译时间：首次约 5 分钟

### 类型检查（快速验证，不生成 .exe）

```powershell
cd front
cargo check
```

## 运行

### 前置条件：后端必须先启动

```powershell
# 在项目根目录
.venv\Scripts\activate
python app.py
# 后端默认监听 http://localhost:5000
```

### 启动前端

```powershell
# 方式 1：直接运行 exe
.\front\target\x86_64-pc-windows-msvc\debug\datavisual-frontend.exe

# 方式 2：通过 cargo run
cd front
cargo run
```

### 环境变量配置

前端通过环境变量配置后端地址和高级参数：

```powershell
# 必需：后端地址（默认 http://localhost:5000）
$env:BACKEND_URL = "http://localhost:5000"

# 必需：API Key（如果后端启用了认证）
$env:API_KEY = "your-api-key"

# 可选：模型配置
$env:MODEL_URL = "https://api.openai.com/v1"
$env:MODEL_TYPE = "openai"
$env:MODEL_API_KEY = "your-model-api-key"

# 可选：提示词
$env:MCP_PROMPT = "..."
$env:SKILL_PROMPT = "..."
```

## 常见问题

### Q: `error: linker 'link.exe' not found`

A: 安装 VS Build Tools 2022，勾选 "MSVC v143 C++ x64/x86 生成工具"。

### Q: 编译报错 `edition 2024 is unstable`

A: 更新 Rust：`rustup update stable`，确认 `rustc --version` >= 1.85。

### Q: 前端启动后连接后端失败

A: 确认后端已启动（`python app.py`），且 `BACKEND_URL` 环境变量正确。

### Q: WebSocket 连接失败

A: 确认后端安装了 `flask-sock`（`pip install flask-sock`）。前端会自动回退到轮询模式。
