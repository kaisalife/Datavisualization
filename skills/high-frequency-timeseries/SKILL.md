# 高频/大样本时间序列

## 适用判断
- 时间列粒度很细（秒/毫秒/分钟），或单条时间序列有上千行。
- 用户关心趋势、波动、异常时段，而不是逐点读数。
- 如果是 OHLC/开盘最高最低收盘，优先考虑 `financial-candlestick` 技能，不要画四条价格线。

## 规划阶段
- 图表类型优先 Line；Area 只用于累计量/份额，或用户明确要面积图。
  温度、价格这类远离 0 的指标用面积图会被 0 基线压平，看不出真实波动。
- 如果用户明确要看区间对比，可用 Bar，但不要把长趋势拆成上百根柱子。
- 在 assumptions 里写明聚合口径，例如“按 5 分钟收盘价/均值聚合后展示”。
- 不要在 plan 里要求逐点标签；密集时序的标签必然重叠。

## 生成阶段
1. 先确认时间列并转成 datetime：
   ```python
   df["时间"] = pd.to_datetime(df["时间"], errors="coerce")
   df = df.dropna(subset=["时间"]).sort_values("时间")
   ```
2. 根据时间跨度选窗口，让最终点数大致落在 300–1500：
   - 几小时的秒级数据：1–5 分钟；
   - 几天的分钟级数据：15 分钟–1 小时；
   - 几个月的日级数据：不需要聚合。
3. 聚合规则要符合业务语义，不能一律求和：
   - 价格/累计值：`last`（或 OHLC）；
   - 传感器/温度/压力：`mean`；
   - 产量/计数：`sum`；
   - 异常检测：同时保留 `min` / `max`，不要只取平均把尖峰抹平。
4. 用 `pd.Grouper` / `resample` 聚合后 reset_index，再画图。示例：
   ```python
   work = df.set_index("时间").resample("5min").agg({"温度": "mean", "压力": "mean"}).reset_index()
   ```
5. 多指标时最多保留 8 条线；更多指标先看 `many-series-timeseries` 技能。
6. 副标题注明聚合粒度，例如「5 分钟均值」；不要让用户误以为画的是原始逐秒值。
7. 折线关闭点标记（`is_symbol_show=False`），线宽 1.5–2；数据点仍会由 ECharts 自动抽稀。
8. 坐标轴名称写指标 + 单位；时间轴标签交给 ECharts 自动间隔，不要强行 `interval=0`。
9. 多系列时保持视觉一致：要么都画折线，要么都给面积；不要只给其中一条加面积填充。

## 不要做
- 不要为了“看起来点很多”而把原始 10 万行直接塞进 HTML。
- 不要在没有说明的情况下丢掉离群点；需要时可以额外用散点/标记线标出异常。
- 不要把不同量纲（温度、压力、流量）硬放在同一个 y 轴而不说明。
